# Conventional Commits — Enforced Rules

1. MUST format all commit messages as: `<type>[optional scope]: <description>`
2. MUST use valid types: feat, fix, docs, style, refactor, perf, test, build, ci, chore, revert
3. MUST keep first line ≤ 50 characters total
4. MUST use imperative mood in description ("add" not "added")
5. MUST indicate breaking changes with `!` after type/scope or `BREAKING CHANGE:` footer
6. NEVER use invalid or custom types
7. NEVER omit the colon and space after type/scope
8. ALWAYS use lowercase for type (never "Feat" or "FIX")
