# ESLint Configuration — Enforced Rules

1. MUST run ESLint check before any git commit
2. MUST fix all ESLint errors immediately when they occur
3. NEVER accumulate ESLint errors across files
4. MUST run `npm run lint` after creating or modifying any JS/TS file
5. MUST use `--fix` flag for auto-fixable issues before manual fixes
6. NEVER use eslint-disable comments without explaining why in a code comment
