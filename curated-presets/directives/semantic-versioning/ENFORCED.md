# Semantic Versioning — Enforced Rules

1. MUST increment version in package.json for every feature or bugfix
2. MUST use MAJOR.MINOR.PATCH format (e.g., 1.2.3)
3. MUST bump MAJOR for incompatible/breaking API changes
4. MUST bump MINOR for backward-compatible new functionality
5. MUST bump PATCH for backward-compatible bug fixes
6. MUST reset lower version numbers to 0 when incrementing a higher level
7. NEVER skip version increments for user-facing changes
